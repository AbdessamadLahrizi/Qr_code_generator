# QR Code Generator 🐍🔲

[![Python Version](https://img.shields.io/badge/python-3.7%2B-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A Python program that generates customizable QR codes from text, URLs, contact info, and WiFi credentials. Save outputs as PNG, JPG, or SVG files.

## Features ✨

- Generate QR codes from:
  - URLs/websites 📍
  - Plain text 📝
  - Phone numbers 📱
  - Email addresses 📧
  - WiFi credentials 📡
- Customize colors 🎨 and sizes
- Error correction support
- CLI and GUI versions
- Multiple output formats (PNG, JPG, SVG)

## Installation 📦

```bash
# Clone repository
git clone https://github.com/AbdessamadLahrizi/Qr_code_generator.git

# Install dependencies
pip install qrcode[pil] python-dotenv
```
